# 🚀 Single Server Configuration using Ansible

## 📌 Overview

This project demonstrates how to automate a web server setup using Ansible on an EC2 instance.

## ⚙️ What I Did

* Installed Ansible on EC2
* Created inventory file
* Ran ad-hoc commands
* Installed and started Nginx

## 🛠️ Tech Stack

* Ansible
* AWS EC2
* Linux
* Nginx

## 🚀 Steps

1. Install Ansible
2. Create inventory
3. Run ping
4. Install nginx
5. Start service

## 🌐 Output

Nginx successfully deployed on EC2.
